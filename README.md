# GitHub Trail

Welcome, investigator. This repository contains five LearnSec challenges. Explore the files and repository history to find each flag.

## Rules
- Use only this repository and its Git history.
- Do not attack GitHub or other users.
- Submit flags exactly as discovered; flags are case-sensitive.

## Challenges
1. **Forgotten README** — Look through the challenge folder for the overlooked note.
2. **Comment Left Behind** — Inspect the source code, not just what it prints.
3. **The Previous Version** — A file changed. Git remembers what used to be there.
4. **Hidden in Plain Sight** — The clue is encoded. Identify the encoding and decode it.
5. **Branching Secrets** — Not every clue is on the default branch. Inspect the available branches.

Good luck!
